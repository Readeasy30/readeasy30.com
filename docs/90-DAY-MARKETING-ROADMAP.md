# ReadEasy30 + MathEasy30 Free Education Growth Roadmap

## Mission

Build trusted daily learning platforms. Both sites remain 100% free.

No ads. No payments. No affiliate links. No forced conversions.

The goal is useful learning resources, repeat practice, and trust.

## Audiences

### ReadEasy30
- Parents supporting reading at home
- Teachers and tutors
- Adult and ESL learners

### MathEasy30
- Parents helping children with math
- Homeschool families
- Elementary intervention support

## Growth Engine

Primary channels:

1. SEO - useful answers for specific learning needs
2. Pinterest - visual search discovery
3. Email - optional learning resource delivery and retention
4. Short video - lightweight discovery

## Days 1-30: Foundation

- Finalize audience paths
- Create free learning resources
- Build resource landing pages
- Publish high-intent SEO pages
- Start Pinterest publishing
- Connect analytics

Targets:
- 20-30 useful pages across both sites
- First resource downloads

## Days 31-60: Expand Winners

- Review search impressions
- Expand successful topics
- Improve internal linking
- Improve resource discovery
- Create more assets from proven topics

## Days 61-90: Build Learning Habits

- Create challenge learning paths
- Improve recommendations between lessons
- Increase returning visitors
- Document successful content formats

## Weekly Operating System

- Publish 3-5 useful pages per site
- Create 20-35 Pinterest assets
- Create 3 short educational videos
- Review analytics

## Content Rules

Create pages that answer real needs:

- Who is this for?
- What skill does it teach?
- How should it be used?
- What should the learner do next?

Automation should multiply proven learning resources, not create unlimited low-value content.
