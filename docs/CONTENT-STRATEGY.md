# ReadEasy30 Content Strategy

## Rule
Create useful learning resources first. Automation supports quality.

## Core Audiences

- Parents
- Teachers and tutors
- Adult and ESL learners

## Content Types

- Daily practice pages
- Skill guides
- Printable resources
- Parent support pages
- Reading challenges

## Content Standard

Every page should answer:

1. Who is this for?
2. What skill does it teach?
3. How should it be used?
4. What is the next practice step?

## Priority Topics

- Reading fluency
- Phonics
- Comprehension
- Vocabulary
- Adult reading confidence
- ESL reading support
