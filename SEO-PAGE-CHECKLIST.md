# ReadEasy30 SEO Page Checklist

Use this checklist before publishing or updating any public ReadEasy30 page.

## Allowed SEO Tactics

Use these safe tactics:

- Add stronger schema when it accurately describes the page.
- Use clean headings in a logical order.
- Add direct Q&A or FAQ blocks that answer real reader questions.
- Keep `sitemap.xml` and `robots.txt` current.
- Tie YouTube videos to exact landing pages when real videos exist.
- Use precise, plain-language entity wording.

Do not use:

- thin programmatic pages
- fake backlinks
- keyword stuffing
- mass AI pages without review
- fake traffic or click automation
- browser auto-click scripts
- video schema before a real video exists
- ranking guarantees

## Required Page Basics

Every public page should have:

- one unique `<title>`
- one clear meta description
- `robots` meta tag when appropriate
- canonical URL
- one clear H1
- logical H2/H3 headings
- readable intro that answers the main question
- short paragraphs
- helpful internal links
- footer navigation
- sitemap entry
- mobile-friendly layout

## Internal Link Targets

When relevant, link to:

- `app.html`
- `app.html#assessmentBox`
- `printable-reading-worksheets.html`
- `worksheet.html`
- `parent-tutor-guide.html`
- one related topic page

## FAQ Rules

FAQ sections should:

- answer real questions
- use calm plain language
- avoid hype
- avoid medical, legal, or school-replacement claims
- point to the next useful page when helpful

## Video Rules

Only add video embeds or video schema after a real video exists.

A video-ready page should have:

- exact landing page URL
- planned video title
- short summary or transcript area
- no empty video placeholder embed

## Trust Rules

ReadEasy30 should always sound:

- calm
- practical
- respectful
- no-shame
- learner-safe
- helpful without overpromising

Do not promise that any learner will reach a grade level by a fixed date.
