Functional literacy worksheet 2

Reading Signs and Simple Instructions

Print this worksheet to practice everyday reading skills. Learners read signs, notices, and short instructions, then answer questions using proof from the text.

Functional literacySignsSimple instructionsAdult-friendlyESL-friendlyNo subscription needed

No subscription is needed. No paid tool is required. This page prints from your browser.

How to Use This Page

  1. Print the worksheet.
  2. Read each sign or instruction slowly.
  3. Underline the words that tell what to do.
  4. Answer one question at a time.
  5. Look back at the text before writing each answer.

🫧 Bubbles Tip

Signs and instructions usually tell you what to do, where to go, or what rule to follow. Look for action words like stop, bring, wait, wash, call, or enter.

Part 1Reading signs

Sign 1: Community Room Notice

COMMUNITY ROOM
OPEN 9:00 AM - 5:00 PM
PLEASE SIGN IN AT THE FRONT DESK

Questions

  1. What room is this sign for?
  2. What time does the room open?
  3. What time does the room close?
  4. Where should visitors sign in?
Part 2Reading safety instructions

Instruction Card: Before Using the Computer

Before using the computer:

  1. Wash or clean your hands.
  2. Ask the helper for your login card.
  3. Use headphones if you play sound.
  4. Log out when you are finished.

Questions

  1. What should you do before using the computer?
  2. Who should you ask for a login card?
  3. What should you use if you play sound?
  4. What should you do when you are finished?
Part 3Reading a short notice

Notice: Library Book Return

Please return library books to the front desk by Friday at 4:00 PM. If the library is closed, place books in the outside return box near the main door.

Questions

  1. Where should books be returned?
  2. What day should books be returned by?
  3. What time should books be returned by?
  4. Where should books go if the library is closed?

Words to Know

notice

A short message that gives important information.

sign in

To write your name or record that you arrived.

front desk

The main desk where a helper or worker may sit.

login card

A card with information used to start using a computer or account.

headphones

A tool worn over or in the ears to listen privately.

return box

A box where items can be placed when a building is closed.

Helper Answer Key

Sign: Community Room; 9:00 AM; 5:00 PM; front desk.

Computer instructions: clean hands; helper; headphones; log out.

Library notice: front desk; Friday; 4:00 PM; outside return box near the main door.
