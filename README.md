# ReadEasy30

ReadEasy30 is a starter website for 30 days of reading practice.

The goal is simple:

- 30 days
- 30 minutes a day
- AI-led reading support
- Built with GitHub and Cloudflare

## Files

- `index.html` is the home page.
- `day1.html` is the first reading lesson.
- `css/style.css` controls the page design.
- `lessons/lessons.js` stores lesson sentences.
- `assets/` is where images can go later.
---

# Project Goals

ReadEasy30 is designed to help struggling readers improve reading ability through simple daily lessons and AI-assisted support.

The platform is focused on:
- simplicity
- accessibility
- mobile-friendly design
- beginner readers
- fast loading speed
- encouraging learning experience
