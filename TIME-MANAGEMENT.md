# ReadEasy30 Time Management

## Main Rule

Keep building through safe work. Do not stop for routine safe updates.

## Work Order

Each work session should move ReadEasy30 forward in this order:

1. Protect the locked simple file structure.
2. Fix broken files or links.
3. Preserve the working lesson engine.
4. Improve reading lesson quality.
5. Improve mobile UX.
6. Improve parent/helper support.
7. Add useful topic pages.
8. Add worksheet planning.
9. Update project instructions and status files.

## Do Not Waste Time On

- repeated planning without edits
- recreating files that already exist
- switching frameworks
- redesigning from scratch
- asking for approval on normal safe updates
- tiny fragile patches when a clean section update is safer

## Stop Only For

- blocked tool writes
- private keys or credentials
- payment setup
- live tracking setup
- live monetization setup
- deleting major working code
- changing the tech stack
- open-ended chatbot behavior without safety controls

## Progress Rhythm

Make safe commits in small groups.

After several commits, report:

- files changed
- what improved
- what is next
- any blocked item

## Current Build Priority

1. Keep the 30-day reading app stable.
2. Improve lesson quality and progression.
3. Improve mobile UX.
4. Add parent/helper support.
5. Add topic pages.
6. Add printable worksheet planning.
7. Add future monetization only after useful content exists.

## Default Action

When unsure, improve the existing simple HTML, CSS, and JavaScript site instead of starting over.
