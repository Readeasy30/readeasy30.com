# ReadEasy30 Content Plan

Date created: 2026-05-28

## Goal

Build ReadEasy30 into a trusted reading-practice website for learners who need calm, clear, daily support.

Primary users:

- children learning to read
- adults with weak reading skills
- ESL learners
- older learners returning to basics
- parents and tutors helping a learner
- struggling readers who need no-shame support

## Voice rule

Use plain language. Aim for grade 7-9 readability on public pages. Keep learner-facing lesson text even simpler when possible.

Bubbles should be calm, kind, and practical. Bubbles should not act like an open-ended chatbot.

## Current content cluster

Existing public content includes:

- daily reading practice
- calm 30-minute reading practice
- adult reading practice
- adult reading practice without shame
- ESL reading practice
- everyday English for ESL learners
- parent/tutor guide
- reading levels from beginner to Grade 8
- sample reading worksheet

## Internal linking rule

Every new page should link to:

- Home
- Lesson App
- Parent / Tutor Guide
- Privacy
- Terms

Every new page should also link to one closely related content page.

## Quality rule

Do not create thin pages. Each page should answer a real user need and give a clear next action.
