# ReadEasy30 Locked Architecture

## Current Architecture

ReadEasy30 uses plain static web files.

No build system is required.

## Files

| File | Purpose |
|---|---|
| `index.html` | Public homepage |
| `app.html` | Reading lesson app |
| `app.js` | Lesson data and app behavior |
| `css/style.css` | Styling for homepage and lesson app |

## Deployment

The project is deployed as a static website.

## Locked Technology

Use:

- HTML
- CSS
- JavaScript
- GitHub Pages or static hosting

Do not use:

- React
- Vite
- Node build tools
- npm dependency workflow
- complicated routing
- database backend yet

## Future Backend

Possible future tools:

- Supabase
- Cloudflare Workers
- OpenAI API
- GitHub Actions

But none should be added until the static MVP is stable.
