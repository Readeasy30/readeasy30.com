# ReadEasy30 Printable Worksheets Plan

Last updated: 2026-06-06

## Purpose

Printable worksheets are a trust-building path for ReadEasy30.

They should support the free reading app, not distract from it.

## Current rule

Live phone and desktop QA comes first.

Do not build paid worksheet products until the free core is stable, tested, and useful.

Do not add payment, checkout, live affiliate links, or ads without direct approval.

## Current reading path alignment

The worksheet plan should support the current A-H reading path:

- Level A — early-reader confidence
- Level B — Grade 1 path
- Level C — Grade 2 path
- Level D — Grade 3 path
- Level E — Grade 4 path
- Level F — Grade 5 path
- Level G — Grades 6-7 path
- Level H — Grade 8 readiness

## Free worksheet priorities

Start with free pages that support real practice:

1. Reading log
2. Vocabulary practice sheet
3. Main idea practice sheet
4. Proof-finding practice sheet
5. Sequence practice sheet
6. Parent/tutor session checklist
7. Adult practical reading worksheet
8. ESL everyday reading worksheet

## Worksheet format

Each worksheet should use:

- large readable text
- short instructions
- plenty of white space
- no shame language
- simple answer areas
- optional helper notes
- phone-friendly page links
- print-friendly layout when possible

## Premium ideas for later

Only after the free core works well and live QA passes:

- Level A-B printable pack
- Level C-D printable pack
- Level E-F printable pack
- Level G-H printable pack
- adult practical reading pack
- ESL daily reading pack
- tutor progress binder

## Safe next action

After live QA passes, improve the existing worksheet hub and free worksheet pages.

Do not create paid packs first.

Do not create checkout pages first.

Do not create ads first.

Build trust first.

## Stop rule

Stop before payment setup, affiliate links, live ads, tracking scripts, accounts, uploads, scraping, public AI tools, or framework migration.
