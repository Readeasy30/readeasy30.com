# ReadEasy30 App 240 Preview Target

Goal: add a separate 240-day preview app page before replacing the current lesson app.

## Target page

- File: `app-240.html`
- Purpose: preview Days 1-240 using `curriculum-240.js`.
- Safety: does not replace `app.html`.

## Target behavior

1. Load `curriculum-240.js`.
2. Show a day selector for Days 1-240.
3. Show the selected day, level, focus, and goal.
4. Give a simple 30-minute practice plan.
5. Link back to the current stable app.

## Current status

The source curriculum, data file, public curriculum page, and app helper are complete. The separate preview app page is the next small patch.
